# Photographer Portfolio Website

A modern, responsive photographer portfolio website built with Next.js and Material UI.

## Features

- Responsive design optimized for all devices
- Image gallery with carousel/slider functionality
- Fast image loading and optimization
- Modern UI components using Material UI
- SEO friendly structure

## Tech Stack

- Next.js 14
- TypeScript
- Material UI
- Next.js Image Optimization
- CSS Modules

## Project Structure

```
├── src/
│   ├── app/          # Next.js app directory
│   ├── components/   # Reusable UI components
│   ├── styles/       # Global styles and theme
│   └── types/        # TypeScript type definitions
├── public/           # Static assets
├── journey.md        # Sprint planning and tasks
└── work-log.md       # Development changelog
```

## Getting Started

1. Install dependencies:
```bash
yarn install
```

2. Run the development server:
```bash
yarn dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Development

- Check `journey.md` for current sprint tasks and progress
- View `work-log.md` for development history and technical decisions
